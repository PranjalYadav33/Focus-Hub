# 🚀 Deploy Focus Hub to GitHub

## Quick Deploy Steps

### 1. Initialize Git Repository
```bash
git init
git remote add origin https://github.com/PranjalYadav33/Focus-Hub.git
```

### 2. Add and Commit Files
```bash
git add .
git commit -m "feat: Focus Hub - refined productivity app with modern design"
```

### 3. Push to GitHub
```bash
git branch -M main
git push -u origin main
```

### 4. Enable GitHub Pages
1. Go to https://github.com/PranjalYadav33/Focus-Hub
2. Click **Settings** tab
3. Scroll to **Pages** section
4. Source: Select **"GitHub Actions"**
5. Click **Save**

### 5. Wait for Deployment
- GitHub Actions will automatically build and deploy
- Takes 2-5 minutes
- Check **Actions** tab to see progress

### 6. Access Your Live Site
**https://pranjalyadav33.github.io/Focus-Hub/**

2. Ensure repository is public
3. Verify GitHub Pages is enabled with "GitHub Actions" source
4. Check that all files are committed and pushed
